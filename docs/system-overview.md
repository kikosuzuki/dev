# YCS コンサルタント予約システム — システム概要書

**作成日:** 2026年4月22日
**バージョン:** 1.0

---

## 1. システムの目的

本システムは、コンサルタントとクライアント（会員・ゲスト）をつなぐ **オンライン予約管理プラットフォーム** である。予約の受付からスケジュール管理、外部サービス連携（Google カレンダー / Chatwork / LINE）、通知・リマインダー、統計レポートまでを一元的に管理する。

**本番URL:** https://ycscampaign.com/consul/consultation

---

## 2. 利用者と役割

| ロール | 対象 | 主な利用シーン |
|--------|------|----------------|
| **ゲスト** | 未登録の相談希望者 | Webページから個別相談を予約（アカウント不要） |
| **会員** | 登録済みの利用者 | コンサルタント検索・予約・レビュー・お気に入り管理 |
| **コンサルタント** | 相談対応スタッフ | スケジュール公開・予約管理・相談記録・Google カレンダー連携 |
| **管理者** | システム運営者 | ユーザー管理・代理予約・統計・システム設定・全体監視 |

## 4. 機能一覧

### 4.1 予約管理
| 機能 | 説明 |
|------|------|
| ゲスト予約 | アカウント不要の個別相談予約（一覧/カレンダー表示） |
| 会員予約 | ログイン後にコンサルタントを選んで予約 |
| 管理者代理予約 | 管理者が会員・ゲストの代わりに予約作成 |
| 予約キャンセル | 理由付きキャンセル（通知スキップ可能） |
| 相談記録 | 結果（成功/失敗/保留）・メモ・重要事項発行の記録 |
| 誤操作リカバリー | 管理者が誤って完了にした相談記録を初期化し、確定済みに差し戻す |
| CSV エクスポート | フィルター条件付きの予約一覧ダウンロード |

### 4.2 スケジュール管理
| 機能 | 説明 |
|------|------|
| 個別作成 | 日付・時間を指定して予約枠を1件ずつ登録 |
| 一括作成 | 日付範囲・曜日・時間帯を指定して複数枠を一括生成（祝日スキップ対応） |
| Google カレンダー重複チェック | 登録時に Google カレンダーの予定と照合し、重複枠を自動スキップ |
| 自動ブロック/復活 | バッチ処理で定期的にカレンダーと照合し、枠の表示/非表示を自動制御 |
| 予約受付 ON/OFF | コンサルタント単位で予約受付を停止/再開 |

### 4.3 通知・リマインダー
| 機能 | 説明 |
|------|------|
| 予約確認通知 | 予約作成時にメール/LINE/Chatwork で通知 |
| キャンセル通知 | キャンセル時に関係者に通知 |
| 前日リマインダー | 指定時刻に前日通知 |
| 当日リマインダー | 指定時刻に当日通知 |
| 直前リマインダー | 予約N分前に通知 |
| 朝の Chatwork 通知 | 当日の予約一覧をコンサルタントに送信 |

### 4.4 外部サービス連携
| サービス | 用途 |
|----------|------|
| Google カレンダー | 予約イベントの自動作成/削除、重複チェック |
| Chatwork | システム通知、個別メッセージ送信 |
| LINE | プッシュメッセージ通知 |
| SMTP (Xserver) | メール送信 |

### 4.5 管理機能
| 機能 | 説明 |
|------|------|
| ユーザー管理 | 登録・編集・有効/無効切替 |
| 統計ダッシュボード | 予約数・完了率・収益・相談結果の集計 |
| コンサルタント統計 | 月別/年別の個人パフォーマンス |
| システム設定 | 予約ルール・リマインダー・テンプレート・外部連携 |
| 監査ログ | 全操作の記録と閲覧 |

## 5. 技術構成

| 項目 | 技術 |
|------|------|
| フレームワーク | Laravel 12 (PHP) |
| フロントエンド | Blade + Alpine.js + Tailwind CSS |
| データベース | SQLite（開発）/ MySQL（本番） |
| メール | SMTP（Xserver） |
| ホスティング | Xserver |
| 外部API | Google Calendar API / LINE Messaging API / Chatwork API |

## 6. 予約のライフサイクル

```
予約作成（ゲスト/会員/管理者）
    │
    ▼
 [承認済み (approved)]
    │
    ├──── キャンセル ────▶ [キャンセル (cancelled)]
    │
    ▼
コンサルタントが完了処理
    │
    ▼
 [完了 (completed)]
    │
    ├──── 誤操作の場合 ──▶ 管理者がリカバリー ──▶ [承認済みに差し戻し]
    │
    ▼
 相談記録の入力（結果・メモ・重要事項）
```

## 7. セキュリティ

| 対策 | 説明 |
|------|------|
| ロールベース認可 | URL単位でロール制御（admin/consultant/user） |
| CSRF保護 | Laravel標準のCSRFトークン |
| パスワードハッシュ | bcrypt による暗号化 |
| セッション管理 | データベースドライバによるセッション管理 |
| 監査ログ | 全重要操作をIPアドレス付きで記録 |
| OAuthトークン管理 | Google リフレッシュトークンの暗号化保存 |
