## 1. システム概要

### アプリケーション名
YCS コンサルタント予約システム

### 概要
コンサルタントの予約管理を行うWebアプリケーション。会員・ゲスト（個別相談）の予約受付、スケジュール管理、Google カレンダー連携、メール / LINE / Chatwork による通知、コンサルタントの成績管理などを統合的に提供する。

### 技術スタック
| 項目 | 技術 |
|------|------|
| フレームワーク | Laravel 12 |
| データベース | SQLite（開発）/ MySQL（本番） |
| メール送信 | SMTP（Xserver） |
| 外部連携 | Google Calendar API, LINE Messaging API, Chatwork API |
| フロントエンド | Blade テンプレート + Alpine.js + Tailwind CSS |

## 2. ユーザーロールと権限

システムには4つのロールがある。

| ロール | 説明 | ログイン |
|--------|------|----------|
| **ゲスト** | 未登録の個別相談予約者 | 不要 |
| **会員（user）** | 登録済みの利用者 | 必要 |
| **コンサルタント（consultant）** | 相談対応を行うスタッフ | 必要 |
| **管理者（admin）** | システム全体を管理 | 必要 |

### ユーザー種別（user_type）
会員ロールには以下の種別がある。管理者・コンサルタントロールには種別はない。

| 種別 | 説明 |
|------|------|
| `member`（会員） | 通常の会員 |
| `consultation`（個別相談） | 個別相談から登録されたユーザー |

## 3. 認証機能

### 3.1 ログイン

**URL:** `/login`

メールアドレスとパスワードでログインする。「ログイン状態を保持する」チェックボックスにより、セッションを延長できる。

ログイン後はロールに応じて自動的にリダイレクトされる:
- 管理者 → `/admin/dashboard`
- コンサルタント → `/consultant/dashboard`
- 会員 → `/user/dashboard`

### 3.2 会員自己登録

**URL:** `/register`

会員（user ロール）として自己登録できる。

| 項目 | 必須 | 説明 |
|------|------|------|
| 氏名 | ○ | ユーザー名 |
| メールアドレス | ○ | ログインID（一意） |
| パスワード | ○ | 確認入力あり |
| 電話番号 | - | 連絡先 |

登録後の動作:
1. ユーザーアカウントが作成される（ロール: user）
2. 登録完了メールが送信される（ログインURL・運営事務局情報を含む）
3. 自動的にログインされ、会員ダッシュボードへリダイレクトされる

### 3.3 パスワードリセット

**URL:** `/forgot-password`

パスワードを忘れた場合のリセット機能。

1. メールアドレスを入力してリセットリンクを送信
2. メール内のリンクから新しいパスワードを設定
3. リセット完了後、ログイン画面へリダイレクト

### 3.4 ログアウト

POST `/logout` でセッションを破棄してログイン画面にリダイレクトされる。

## 4. ゲスト向け機能（個別相談予約）

**URL:** `/consultation`

アカウント登録不要で、コンサルタントとの個別相談を予約できる。

### 4.1 空き日程の閲覧

2つの表示モードで予約可能な時間枠を確認できる。

- **一覧ビュー**: 日付・時間・状態を一覧表示。日付範囲でフィルター可能。30件ずつページネーション。
- **カレンダービュー**: 月ごとのカレンダー形式。各日にち内に予約可能な時間枠を表示。前月・翌月のナビゲーション付き。

※ どのコンサルタントが担当するかはゲストには表示されない（システムが自動割り当て）。

### 4.2 表示制御

以下のシステム設定により表示が制御される。

| 設定 | 説明 |
|------|------|
| 予約受付 ON/OFF | OFF の場合、受付停止ページを表示 |
| 公開日数 | 現在から何日先まで表示するか |
| 最低予約時間 | 現在から何時間後以降の枠のみ表示 |
| 1日最大予約数 | コンサルタント1人あたりの上限に達した枠は非表示 |

### 4.3 予約の作成

予約フォームで以下を入力する。

| 項目 | 必須 | 説明 |
|------|------|------|
| 氏名 | ○ | ゲストの氏名 |
| メールアドレス | ○ | 確認メール送信先 |
| 電話番号 | ○ | 連絡先 |
| 紹介元 | - | どこでこのサービスを知ったか |
| 備考 | - | 相談内容のメモ |

予約作成後の動作:
1. 予約ステータスは即時「承認済み」になる
2. Google カレンダーにイベントが作成される（管理者 + 担当コンサルタント）
3. 通知が送信される（メール / LINE / Chatwork）
4. 完了ページが表示される

## 5. 会員向け機能

**URL:** `/user/*`（ログイン必須）

### 5.1 ダッシュボード
- 直近の予約一覧
- 予約統計

### 5.2 コンサルタント検索
- **一覧表示**: 専門分野・キーワードでフィルター
- **並び替え**: 評価順、料金順、レビュー数順
- **プロフィール閲覧**: 専門分野、経歴、資格、対応言語、レビューを確認

### 5.3 スケジュール閲覧
- コンサルタントの空き枠を日付フィルター付きで検索

### 5.4 予約管理

| 操作 | 説明 |
|------|------|
| 予約作成 | 空き枠を選択して予約 |
| 予約一覧 | ステータスでフィルター（承認済み / キャンセル / 完了） |
| 予約詳細 | 日時、コンサルタント情報、ミーティングURL等を確認 |
| 予約キャンセル | 承認済みの予約をキャンセル |

### 5.5 レビュー
- 完了済みの予約に対して、1〜5段階の評価とコメントを投稿
- 1予約につき1回のみ

### 5.6 お気に入り
- コンサルタントをお気に入りに追加 / 解除（AJAX対応）
- お気に入り一覧の閲覧

### 5.7 プロフィール
- 氏名、電話番号の変更
- パスワード変更
- 通知設定（メール / LINE の ON/OFF）

## 6. コンサルタント向け機能

**URL:** `/consultant/*`（ログイン必須）

### 6.1 ダッシュボード
- 今後の予約一覧
- 予約統計（月別フィルターで対象月を切り替え可能）

### 6.2 スケジュール管理

#### 表示切替
- **カレンダービュー**: 月ごとのカレンダー形式で予約枠を表示。日付セルに空き枠数・予約済み枠数を色分けで表示。前月・翌月ナビゲーション付き。
- **リストビュー**: 日付・時間・ステータス・操作を一覧テーブルで表示。

#### 個別作成
- 日付を指定し、複数の時間枠を一度に登録可能（「枠を追加」ボタンで行追加）
- **所要時間ドロップダウン**（15分 / 30分 / 45分 / 60分 / 90分 / 120分）を選択すると、開始時間入力時に終了時間が自動計算される
- 終了時間の手動変更も可能

#### 一括作成
以下の条件で複数枠を一括生成:

| 項目 | 説明 |
|------|------|
| 開始日〜終了日 | 対象の日付範囲 |
| 曜日選択 | 月〜日から対象曜日をチェック |
| 開始時間〜終了時間 | 1日の対応時間帯 |
| 枠の長さ | 1枠あたりの分数（例: 60分） |
| 祝日スキップ | 日本の祝日を自動スキップ |

※ 日本の祝日は `JapaneseHolidays` ヘルパーで自動計算（元日、建国記念日、天皇誕生日、春分・秋分の日、ハッピーマンデー祝日、振替休日、国民の休日に対応）。

#### 削除
- 予約のない枠のみ削除可能

### 6.3 予約管理

#### フィルター・検索
- **名前・メール検索**: 予約者の名前またはメールアドレスで検索
- **ステータスフィルター**: 全て / 承認済み / 完了 / キャンセル
- **相談結果フィルター**: 成功 / 失敗 / 保留（完了済み予約のみ）
- 紹介者の表示あり（個別相談のみ）

#### 操作

| 操作 | 説明 |
|------|------|
| 完了 | 予約を完了に変更 |
| キャンセル | キャンセル理由を記入してキャンセル |
| 相談記録 | 相談結果（成功/失敗/保留）とメモを記録。重要事項説明書の交付フラグも管理 |
| 内部メモ | 予約に対する内部メモの記録・編集（完了後も編集可能） |
| メール送信 | テンプレートを使って予約者にメール送信（全ステータスの予約で利用可能、プレースホルダー自動置換） |

### 6.4 予約受付 ON/OFF
- プロフィール設定画面のトグルスイッチで、自分の予約受付を ON/OFF できる
- OFF にすると、自分の予約枠がゲスト・会員の予約一覧やカレンダーから**自動的に非表示**になる
- 管理者もユーザー編集画面からコンサルタントごとの受付状態を変更可能
- 管理者による代理予約は、受付 OFF のコンサルタントに対しても作成可能

### 6.5 プロフィール管理

| 項目 | 説明 |
|------|------|
| 専門分野 | コンサルタントの専門分野 |
| 自己紹介 | 経歴・紹介文 |
| 経験年数 | 年数 |
| 資格 | JSON配列で複数登録 |
| 対応言語 | JSON配列で複数登録 |
| ミーティングURL | Zoom / Google Meet 等のデフォルトURL |
| 重要事項説明書URL | 重要事項説明書のダウンロードURL |
| Chatwork ID | Chatwork アカウントID |
| 写真 | プロフィール写真のアップロード |

※ 必須項目（氏名、専門分野、経験年数）にはフォーム上に `*` マークが表示される。

### 6.6 Google カレンダー連携
- Google アカウントとの OAuth 認証
- 同期先カレンダーの選択（複数カレンダーから選択可）
- 連携解除

## 7. 管理者向け機能

**URL:** `/admin/*`（ログイン必須）

### 7.1 ダッシュボード
- 全体統計: ユーザー数、コンサルタント数、予約数、収益
- 相談結果の集計（成功/失敗/保留）
- 月別予約推移グラフ
- 最近の予約一覧

### 7.2 ユーザー管理

#### ユーザー一覧
- ロール別フィルター: 全て / 会員 / コンサルタント / 管理者 / ゲスト
- **名前・メール検索**: 名前またはメールアドレスで絞り込み（ゲストタブでは名前・メール・電話・紹介者で検索可能）
- 各ユーザーのロール、種別（会員のみ）、ステータスを表示
- ゲストタブでは予約に紐づくゲスト情報を一覧表示

#### ユーザー操作

| 操作 | 説明 |
|------|------|
| 新規作成 | 会員またはコンサルタントを作成（コンサルタントは専門分野等も同時設定） |
| 編集 | ユーザー情報・通知設定・管理者メモの変更（種別はロールが「会員」の場合のみ表示） |
| 予約受付 ON/OFF | コンサルタントの予約受付を ON/OFF（コンサルタントロールのみ表示） |
| 有効/無効 | アカウントの有効化 / 無効化 |
| ゲスト編集 | ゲスト予約の名前・メール・電話・紹介元を編集 |
| CW メッセージ | Chatwork ルームにメッセージを送信（設定済みユーザーのみ） |

#### CW メッセージ送信モーダル
- メッセージはユーザーに設定された Chatwork ルーム（Room ID 表示）に送信
- モーダルを開くと Chatwork API で送信先の名前を自動取得して表示

### 7.3 予約管理

#### 予約一覧
以下のフィルター・検索に対応:

| フィルター | 選択肢 |
|------------|--------|
| 名前・メール検索 | 予約者の名前またはメールアドレスで絞り込み |
| 期間 | 今週 / 今月 / 先月 / 全期間 |
| コンサルタント | 全コンサルタントから選択 |
| ステータス | 承認済み / キャンセル / 完了 |
| 予約タイプ | 会員 / ゲスト（個別相談） |
| 相談結果 | 成功 / 失敗 / 保留 |

#### CSV ダウンロード
現在のフィルター条件に合致する予約一覧を CSV ファイルとしてダウンロードできる。

| CSV 出力項目 |
|-------------|
| 予約ID、種別（会員/個別相談）、予約者名、メール、電話番号、紹介者、コンサルタント、予約日、開始時間、終了時間、ステータス、相談結果、備考、管理メモ |

※ UTF-8 BOM 付きで出力されるため、Excel で直接開いても文字化けしない。

#### 新規予約作成（管理者による代理予約）
管理者がユーザーまたはゲストの代わりに予約を作成できる。

**手順:**
1. 予約種別を選択（ゲスト / 会員）
2. コンサルタントを選択 → 空き枠が AJAX で動的に読み込まれる
3. 時間枠を選択
4. ゲストの場合: 氏名・メール・電話・紹介元を入力
5. 会員の場合: 会員をドロップダウンから選択
6. 備考・管理者メモを入力（任意）
7. 予約作成 → Google カレンダー同期 + 通知送信

#### その他の操作

| 操作 | 説明 |
|------|------|
| キャンセル | 理由を付けて予約をキャンセル |
| 相談記録 | 結果（成功/失敗/保留）とメモを記録 |
| 管理者メモ | 内部メモの追加・編集 |
| ゲストメール | テンプレートを使ってゲストにメール送信 |

### 7.4 ゲストメール送信
- 事前登録されたテンプレートを選択して送信
- テンプレートのプレースホルダー（後述）を自動置換
- 件名・本文を編集してから送信可能

### 7.5 コンサルタント統計

| 指標 | 説明 |
|------|------|
| 月別予約数 | 承認済み + 完了の合計 |
| 完了率 | 完了 / (完了 + キャンセル) |
| 対応時間 | 完了した予約の合計時間 |
| 収益 | 完了した予約の合計金額 |
| 相談結果 | 成功 / 失敗 / 保留の内訳 |

### 7.6 ユーザー統計
- ユーザー・ゲストの予約パターン分析

### 7.7 システム設定

設定画面はタブ構成で以下の項目を管理:

| タブ | 内容 |
|------|------|
| 予約設定 | 受付 ON/OFF、公開日数、最低時間、1日上限、キャンセルポリシー |
| リマインダー | 前日/当日/N分前リマインダーの ON/OFF と時刻設定 |
| テンプレート | ゲスト向けメールテンプレートの管理 |
| 連携設定 | LINE / Chatwork / Google カレンダーの API 設定 |
| 監査ログ | 直近50件のシステム操作ログ |

### 7.8 スケジュール管理（予約枠の追加）
管理者がコンサルタントの予約枠を代理で追加できる。

- コンサルタントをドロップダウンから選択
- 日付・開始時間・終了時間を指定
- **所要時間ドロップダウン**（15分 / 30分 / 45分 / 60分 / 90分 / 120分）で終了時間を自動計算

### 7.9 Google カレンダー連携（管理者）
- 管理者の Google アカウントで OAuth 認証
- 同期先カレンダーの選択
- 連携の有効/無効切り替え

## 8. 通知システム

### 8.1 通知チャネル

| チャネル | 対象 | 設定方法 |
|----------|------|----------|
| メール | 全ユーザー | ユーザー設定の `notify_email` |
| LINE | LINE連携済みユーザー | ユーザー設定の `notify_line` |
| Chatwork | Chatwork設定済みユーザー | ユーザー設定の `notify_chatwork` |
| Chatwork（システム） | 管理用ルーム | システム設定の `chatwork_room_id` |

### 8.2 通知タイプ

| タイプ | 送信先 | タイミング |
|--------|--------|------------|
| 登録完了 | 自己登録した会員 | 会員登録完了時 |
| 予約確認 | 予約者 + コンサルタント + システムCW | 予約作成時 |
| キャンセル通知 | 予約者 + コンサルタント + システムCW | キャンセル時 |
| 前日リマインダー | 予約者 + コンサルタント | 予約前日の指定時刻 |
| 当日リマインダー | 予約者 + コンサルタント | 予約当日の指定時刻 |
| 直前リマインダー | 予約者 + コンサルタント | 予約N分前 |
| 朝の通知 | コンサルタント（Chatwork） | 当日朝 |

### 8.3 テンプレートプレースホルダー

テンプレート内で以下のプレースホルダーが自動置換される。

| プレースホルダー | 置換内容 |
|------------------|----------|
| `{name}` | 予約者の氏名 |
| `{date}` | 予約日時 |
| `{consultant}` | コンサルタント名 |
| `{meeting_url}` | ミーティングURL |
| `{chatwork_id}` | コンサルタントの Chatwork ID |
| `{important_document_url}` | コンサルタントの重要事項説明書URL |

### 8.4 重複送信防止
通知の重複送信を防ぐため、以下の仕組みが実装されている。

| 対策 | 説明 |
|------|------|
| NotificationLog チェック | 同一予約・同一チャネル・同一タイプの通知が直近1時間以内に送信済みの場合はスキップ |
| システムルーム重複防止 | コンサルタントの個人 Chatwork ルームとシステム通知ルームが同一の場合、システム通知をスキップ |
| 朝の通知フラグ | `morning_chatwork_sent` フラグにより、スケジューラーが複数回実行されても重複送信しない |
| リマインダーフラグ | `reminder_day_before_sent` / `reminder_day_of_sent` / `reminder_10min_sent` フラグで各リマインダーの送信を1回に制限 |

### 8.5 通知ログ
全ての通知は `notification_logs` テーブルに記録される。

| 記録項目 | 説明 |
|----------|------|
| チャネル | email / line / chatwork / chatwork_system |
| タイプ | booking_confirmed / reminder_day_before 等 |
| ステータス | sent / failed |
| エラー内容 | 失敗時の詳細 |

## 9. Google カレンダー連携

### 9.1 概要
予約作成時に Google カレンダーにイベントを自動作成する。管理者カレンダーとコンサルタント個人カレンダーの**2つのカレンダー**に同時作成される。

### 9.2 イベント内容

| 項目 | 内容 |
|------|------|
| タイトル | 予約者名 + コンサルタント名 |
| 日時 | 予約の開始〜終了時間 |
| 出席者 | 予約者メール + コンサルタントメール |
| リマインダー | メール（1日前）+ ポップアップ（10分前） |
| 説明 | 予約タイプ、備考等 |

### 9.3 設定方法

**管理者カレンダー:**
1. 管理画面 → 連携設定 → Google カレンダーで OAuth 認証
2. カレンダー一覧から同期先を選択
3. 有効/無効を切り替え

**コンサルタントカレンダー:**
1. コンサルタント画面 → プロフィール → Google カレンダーで OAuth 認証
2. カレンダー一覧から同期先を選択

### 9.4 動作
- 予約作成 → 両方のカレンダーにイベント作成
- 予約キャンセル → 両方のカレンダーからイベント削除
- 連携はオプション（エラー時も予約処理は継続）

## 10. Chatwork 連携

### 10.1 システム通知
管理画面の連携設定で以下を設定:

| 設定 | 説明 |
|------|------|
| API トークン | Chatwork API トークン |
| ルーム ID | システム通知先のルーム |
| 有効/無効 | 通知の ON/OFF |

予約確認・キャンセル時に、設定されたルームにメッセージが自動送信される。コンサルタントへのメンション（`[To:account_id]`）付き。

### 10.2 ユーザー個別通知
各ユーザーに以下を設定すると、そのユーザーの Chatwork ルームに個別通知が送られる。

| ユーザー設定 | 説明 |
|-------------|------|
| `chatwork_id` | Chatwork のアカウント ID |
| `chatwork_room_id` | 通知先のルーム ID |
| `notify_chatwork` | 通知の ON/OFF |

### 10.3 管理者からのメッセージ送信
ユーザー管理画面の「CW」ボタンから、ユーザーに設定された Chatwork ルームにメッセージを送信できる。送信時に Chatwork API でルームメンバーの名前を取得して表示する。

## 13. データベース構成

### テーブル一覧

| テーブル | 説明 |
|----------|------|
| `users` | ユーザー（全ロール共通） |
| `consultant_profiles` | コンサルタントプロフィール（専門分野、ミーティングURL、重要事項説明書URL 等） |
| `consultant_schedules` | コンサルタントの予約枠 |
| `bookings` | 予約 |
| `reviews` | レビュー・評価 |
| `favorites` | お気に入り（中間テーブル） |
| `notification_logs` | 通知送信ログ |
| `system_settings` | システム設定（Key-Value） |
| `audit_logs` | 監査ログ |
| `guest_message_templates` | ゲスト向けメールテンプレート |

### 主要リレーション

```
users ─┬── consultant_profiles (1:1)
       ├── consultant_schedules (1:N) ── bookings (1:N)
       ├── bookings as user (1:N)
       ├── bookings as consultant (1:N)
       ├── reviews as reviewer (1:N)
       ├── reviews as consultant (1:N)
       └── favorites (M:N)

bookings ── reviews (1:1)
bookings ── notification_logs (1:N)
```

### 予約ステータスフロー

```
作成 → [approved] → [completed]  （正常完了）
                  → [cancelled]   （キャンセル）
```

## 14. 技術仕様

### URL 構成

| パス | 対象 |
|------|------|
| `/consultation/*` | ゲスト（個別相談）予約 |
| `/login`, `/register` | 認証（ログイン・会員登録） |
| `/forgot-password`, `/reset-password/*` | パスワードリセット |
| `/user/*` | 会員機能 |
| `/consultant/*` | コンサルタント機能 |
| `/admin/*` | 管理者機能 |
| `/api/*` | API エンドポイント |
| `/google/callback` | Google OAuth コールバック（共通） |

### API エンドポイント

| メソッド | パス | 説明 |
|----------|------|------|
| GET | `/api/chatwork/members/{roomId}` | Chatwork ルームメンバー取得 |
| GET | `/admin/bookings/schedules?consultant_id=N` | コンサルタントの空き枠取得（JSON） |
| GET | `/consultant/google/calendars` | Google カレンダー一覧取得（JSON） |
| GET | `/admin/google/calendars` | 管理者 Google カレンダー一覧取得（JSON） |

### サービスクラス

| クラス | 役割 |
|--------|------|
| `NotificationService` | メール / LINE / Chatwork 通知の一元管理 |
| `GoogleCalendarService` | Google カレンダーイベントの作成・削除・同期 |
| `LineNotificationService` | LINE Messaging API 連携 |
| `ChatworkService` | Chatwork API 連携 |

### ヘルパークラス

| クラス | 役割 |
|--------|------|
| `JapaneseHolidays` | 日本の祝日判定（元日、成人の日、建国記念日、天皇誕生日、春分の日、秋分の日、ハッピーマンデー、振替休日、国民の休日に対応） |

### 主要スコープ（ConsultantSchedule）

| スコープ | 説明 |
|----------|------|
| `upcoming()` | 現在以降のスケジュールのみ |
| `withinDailyLimit()` | 1日上限に達していないスケジュールのみ |
| `acceptingBookings()` | 予約受付が ON のコンサルタントのスケジュールのみ |

### 監査ログ
全ての重要な操作は `audit_logs` テーブルに記録される。

| 記録項目 | 説明 |
|----------|------|
| 操作ユーザー | 操作を行ったユーザー |
| アクション | booking_created, user_updated 等 |
| 変更前後の値 | JSON形式で記録 |
| IPアドレス | クライアントのIPアドレス |
