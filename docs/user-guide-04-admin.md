# ユーザー説明書（4）管理者向け

**URL:** https://ycscampaign.com/consul/login

---

## ダッシュボード

ログイン後のホーム画面です。

- **全体統計**: ユーザー数、コンサルタント数、予約数、収益
- **相談結果の集計**: 成功 / 失敗 / 保留 の件数
- **月別予約推移グラフ**: 予約数の推移をグラフ表示
- **最近の予約一覧**: 直近の予約を一覧表示

---

## ユーザー管理

**メニュー →「ユーザー管理」**

### ユーザー一覧

タブで切り替えて表示します。

| タブ | 表示内容 |
|------|----------|
| 全て | 全ユーザー |
| 会員 | 会員ロールのユーザー |
| コンサルタント | コンサルタントロールのユーザー |
| 管理者 | 管理者ロールのユーザー |
| ゲスト | ゲスト予約に紐づくゲスト情報 |

名前またはメールアドレスで検索できます。ゲストタブでは電話番号・紹介者でも検索可能です。

### 新規ユーザー作成

1. 「新規作成」ボタンを押します
2. ロール（会員 / コンサルタント）を選択します
3. 氏名・メールアドレス・パスワードを入力します
4. コンサルタントの場合は専門分野等も設定できます
5. 「作成」を押します

### ユーザー編集

ユーザー名を押すと編集画面が表示されます。

| 変更可能な項目 | 説明 |
|---------------|------|
| 氏名・メール・電話番号 | 基本情報 |
| 通知設定 | メール / LINE / Chatwork の ON/OFF |
| Chatwork 設定 | アカウントID・ルームID |
| 管理者メモ | 管理者用の内部メモ |
| ユーザー種別 | 会員 / 個別相談（会員ロールのみ） |
| 予約受付 ON/OFF | コンサルタントのみ表示 |

### アカウントの有効/無効

「有効」「無効」ボタンで切り替えます。無効にするとログインできなくなります。

### ゲスト情報の編集

ゲストタブからゲスト予約の名前・メール・電話・紹介元を編集できます。

### Chatwork メッセージ送信

Chatwork ルームが設定済みのユーザーに「CW」ボタンが表示されます。

1. 「CW」ボタンを押すとモーダルが開きます
2. 送信先のルーム名とメンバーが自動表示されます
3. メッセージを入力して「送信」を押します

## 予約管理

**メニュー →「予約管理」**

### 予約一覧の検索・絞り込み

| フィルター | 選択肢 |
|------------|--------|
| 名前・メール検索 | 予約者の名前またはメールで絞り込み |
| 期間 | 今週 / 今月 / 先月 / 全期間 |
| コンサルタント | ドロップダウンから選択 |
| ステータス | 承認済み / キャンセル / 完了 |
| 予約タイプ | 会員 / ゲスト（個別相談） |
| 相談結果 | 成功 / 失敗 / 保留 |

### CSV ダウンロード

1. フィルターで対象の予約を絞り込みます
2. 「CSVダウンロード」ボタンを押します
3. 現在のフィルター条件に合致する予約がダウンロードされます

出力項目: 予約ID、種別、予約者名、メール、電話番号、紹介者、コンサルタント、予約日、開始時間、終了時間、ステータス、相談結果、備考、管理メモ

※ UTF-8 BOM付きで出力されるため、Excelで直接開いても文字化けしません。

### 新規予約の代理作成

1. 「新規予約作成」ボタンを押します
2. 予約種別を選択します（ゲスト / 会員）
3. コンサルタントを選択すると、空き枠が自動で読み込まれます
4. 時間枠を選択します
5. 予約者情報を入力します
   - ゲスト: 氏名・メール・電話・紹介元
   - 会員: ドロップダウンから会員を選択
6. 備考・管理者メモ（任意）を入力します
7. 「予約する」を押します

予約作成後、Google カレンダーへの同期と通知が自動で行われます。

### 予約のキャンセル

1. 「キャンセル」ボタンを押します
2. キャンセル理由を入力します
3. 「通知を送信しない」にチェックを入れると通知をスキップできます
4. 「キャンセルする」を押します

### 相談記録の入力

1. 予約の「相談記録」セクションを開きます
2. 相談結果（成功 / 失敗 / 保留）を選択します
3. 相談メモ（自由記述）を入力します
4. 重要事項説明書を交付済みならチェックを入れます
5. 「保存」を押します

### 相談記録のリカバリー（誤操作時）

コンサルタントが誤って完了にした場合、元に戻せます。

1. 予約の「リカバリー操作」セクションを開きます
2. 「記録を初期化し、確定済みに戻す」ボタンを押します
3. 確認ダイアログで「OK」を押します

**この操作で行われること:**
- 相談結果と重要事項フラグがクリアされます
- 完了状態の場合、ステータスが「承認済み」に戻ります
- 相談メモは保持されます（監査目的）
- 予約日が未来の場合、リマインダーが再発動します
- 監査ログに記録されます

※ このボタンは、予約が「完了」「相談結果あり」「重要事項フラグあり」のいずれかの場合に表示されます。

### 管理者メモ

予約に対する内部メモを記録・編集できます。お客様には表示されません。

### ゲストへのメール送信

1. 「メール送信」ボタンを押します
2. テンプレートを選択すると件名・本文が自動入力されます
3. 内容を編集して「送信」を押します

## スケジュール管理

**メニュー →「スケジュール管理」**

コンサルタントの予約枠を代理で追加できます。

1. コンサルタントをドロップダウンから選択します
2. 日付・開始時間を入力します
3. 所要時間を選択すると終了時間が自動計算されます
4. 「登録する」を押します

---

## スケジュールリクエスト管理

**メニュー →「スケジュールリクエスト」**

ゲストから届いたスケジュールリクエストを管理します。

| タブ | 表示内容 |
|------|----------|
| 未処理 | まだ対応していないリクエスト |
| 処理済み | 対応済みのリクエスト |

### リクエストへの対応
1. リクエストの詳細を確認します（希望日時の候補が表示されます）
2. 「返信メールを送信」で、ゲストにメールで回答できます
3. 「予約を作成」で、リクエストから直接予約を作成できます
4. 「処理済みにする」で、ステータスを更新します

## 統計

### コンサルタント統計

**メニュー →「コンサルタント統計」**

全コンサルタントの月別パフォーマンスを一覧できます。

| 指標 | 説明 |
|------|------|
| 予約数 | 承認済み + 完了の合計 |
| 完了率 | 完了 / (完了 + キャンセル) |
| 対応時間 | 完了した予約の合計時間 |
| 収益 | 完了した予約の合計金額 |
| 相談結果 | 成功 / 失敗 / 保留の内訳 |

コンサルタント名を押すと、年間の詳細統計が表示されます。

### ユーザー統計

**メニュー →「ユーザー統計」**

ユーザー・ゲストの予約パターンを分析できます。

## システム設定

**メニュー →「設定」**

タブで切り替えて各種設定を管理します。

### 予約設定タブ

| 設定 | 説明 |
|------|------|
| 予約受付 ON/OFF | OFF にすると全ての予約受付を停止します |
| 公開日数 | 現在から何日先まで予約枠を表示するか |
| 最低予約時間 | 現在から何時間後以降の枠のみ表示するか |
| 1日上限 | コンサルタント1人あたりの1日の予約上限 |
| キャンセルポリシー | 予約の何時間前までキャンセル可能か |

### リマインダータブ

| 設定 | 説明 |
|------|------|
| 前日リマインダー | ON/OFF と送信時刻の設定 |
| 当日リマインダー | ON/OFF と送信時刻の設定 |
| 直前リマインダー | ON/OFF と何分前に送信するかの設定 |

### テンプレートタブ

ゲスト向けメールテンプレートを管理します。

- テンプレート名・件名・本文を設定できます
- 並び順を変更できます
- 新規追加・編集・削除が可能です

### 連携設定タブ

| 設定 | 説明 |
|------|------|
| LINE | チャネルトークン・シークレットの設定、ON/OFF |
| Chatwork | APIトークン・ルームIDの設定、ON/OFF |
| Google カレンダー | OAuth連携・同期先カレンダーの選択、ON/OFF |

### 監査ログ

直近50件のシステム操作ログが表示されます。操作者・操作内容・対象・日時を確認できます。

## Google カレンダー連携（管理者）

**メニュー →「設定」→ 連携設定タブ**

管理者の Google カレンダーは、全予約のイベントが作成される統合カレンダーです。

### 設定手順
1. 「Googleアカウントと連携」ボタンを押します
2. Google 認証画面でアカウントを選択し、許可します
3. カレンダー一覧から同期先を選択します
4. 「有効」に切り替えます

### 動作
- 予約作成時: 管理者カレンダーにイベントが自動作成されます
- 予約キャンセル時: イベントが自動削除されます
- コンサルタントのカレンダーにも同時に作成/削除されます
