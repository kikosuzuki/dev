# ユーザー説明書（3）コンサルタント向け

**URL:** https://ycscampaign.com/consul/login

---

## ダッシュボード

ログイン後のホーム画面です。

- **本日の予約一覧**: 今日の予約が時間順に表示されます
- **月別統計**: 対象月を切り替えて、予約数・完了率・対応時間などを確認できます

---

## スケジュール管理

**メニュー →「スケジュール管理」**

お客様が予約できる時間枠を管理します。

### 表示の切替

**カレンダー表示**
- 月ごとのカレンダー形式で予約枠を一覧できます
- 各日付に空き枠数・予約済み枠数が色分けで表示されます
- 「前月」「翌月」で月を切り替えます

**リスト表示**
- 日付・時間・ステータス・操作がテーブル形式で表示されます

### 予約枠を個別に作成する

1. 「スケジュール作成」画面を開きます
2. 日付を選択します
3. 開始時間を入力します
4. 所要時間を選択すると、終了時間が自動計算されます（15分 / 30分 / 45分 / 60分 / 90分 / 120分）
5. 「枠を追加」ボタンで、同じ日に複数の枠を一度に登録できます
6. 「登録する」を押します

### 予約枠を一括作成する

複数日にまとめて枠を作成できます。

| 設定項目 | 説明 |
|----------|------|
| 開始日〜終了日 | 対象の日付範囲 |
| 曜日 | 月〜日から対象曜日をチェック |
| 開始時間〜終了時間 | 1日の対応時間帯 |
| 枠の長さ | 1枠あたりの分数（例: 60分） |
| 祝日スキップ | チェックすると日本の祝日を自動スキップ |

例: 「4/1〜4/30、月〜金、10:00〜17:00、60分枠、祝日スキップ」で、平日の1時間枠が自動生成されます。

### Google カレンダー重複チェック

重複チェック用カレンダーを設定済みの場合、枠の作成時に Google カレンダーの予定と自動的に照合されます。

- 既に Google カレンダーに予定がある時間帯の枠は**自動的にスキップ**されます
- スキップされた枠は登録結果に理由付きで表示されます

### カレンダー重複による自動ブロック

システムが10分ごとに Google カレンダーを確認し、予定が入った時間帯の枠を自動的にブロックします。

- ブロックされた枠はカレンダー表示で黄色の「重複」バッジが付きます
- リスト表示では「カレンダー重複」バッジが付きます
- ブロック中の枠はお客様の予約ページに表示されません
- Google カレンダーから予定を削除すると、自動的にブロックが解除されます

### 予約枠を削除する

- リスト表示で、予約のない枠に「削除」ボタンが表示されます
- 予約済みの枠は削除できません

## 予約管理

**メニュー →「予約管理」**

### 検索・絞り込み

| フィルター | 説明 |
|------------|------|
| 名前・メール検索 | 予約者の名前またはメールで検索 |
| ステータス | 全て / 承認済み / 完了 / キャンセル |
| 相談結果 | 成功 / 失敗 / 保留（完了済みのみ） |

### 予約を完了にする

1. 対象の予約の「完了」ボタンを押します
2. ステータスが「完了」に変わります

### 相談記録を入力する

1. 予約の「相談記録」セクションを開きます
2. 以下を入力します

| 項目 | 説明 |
|------|------|
| 相談結果 | 成功 / 失敗 / 保留 から選択 |
| 相談メモ | 相談内容の記録（自由記述） |
| 重要事項説明書 | 交付済みならチェックを入れる |

3. 「保存」を押します

### 予約をキャンセルする

1. 「キャンセル」ボタンを押します
2. キャンセル理由を入力します
3. 「通知を送信しない」にチェックを入れると、お客様への通知をスキップできます
4. 「キャンセルする」を押します

### 内部メモ

予約に対する内部メモを記録できます。完了後も編集可能です。お客様には表示されません。

### お客様にメール送信

1. 予約の「メール送信」ボタンを押します
2. テンプレートを選択すると、件名・本文が自動入力されます
3. 内容を編集して「送信」を押します

※ `{name}` `{date}` などのプレースホルダーは自動的にお客様の情報に置き換わります。

## 予約受付の ON/OFF

**メニュー →「プロフィール」**

プロフィール設定画面のトグルスイッチで、予約受付を ON/OFF できます。

| 状態 | 動作 |
|------|------|
| ON | 予約枠がお客様に表示され、予約が入ります |
| OFF | 予約枠が非表示になり、新規予約が入りません |

※ 既存の予約には影響しません。

## プロフィール管理

**メニュー →「プロフィール」**

| 項目 | 説明 |
|------|------|
| 専門分野（必須） | あなたの専門分野 |
| 自己紹介 | 経歴・紹介文 |
| 経験年数（必須） | 年数 |
| 資格 | 複数登録可能 |
| 対応言語 | 複数登録可能 |
| ミーティングURL | Zoom / Google Meet 等のURL |
| 重要事項説明書URL | ダウンロードURL |
| Chatwork アカウントID | メンション用 |
| 写真 | プロフィール写真のアップロード・削除 |

### パスワード変更
1. 現在のパスワードを入力
2. 新しいパスワードを入力（確認入力あり）
3. 「変更する」を押します

## Google カレンダー連携

**メニュー →「プロフィール」→ Google カレンダーセクション**

### 初回設定
1. 「Google アカウントと連携」ボタンを押します
2. Google の認証画面でアカウントを選択し、許可します
3. 連携完了後、カレンダーの設定ができるようになります

### 同期先カレンダーの選択
予約イベントが自動作成されるカレンダーを選択します。

### 重複チェック用カレンダーの選択
スケジュール登録時・バッチ処理で重複チェックに使うカレンダーを選択します（複数選択可能）。

※ 同期先と重複チェック用は別の設定です。

### 連携の解除
「連携を解除」ボタンで Google カレンダーとの連携を解除できます。
